# MVP сайта для 3D-печатных автодеталей

## Запуск

1. Установите `Node.js` 20+.
2. Выполните `npm install`.
3. Запустите проект: `npm run dev`.
4. Откройте `http://localhost:3000`.

## Что реализовано

- `Next.js + TypeScript + Tailwind CSS`
- многостраничная структура на `app router`
- общие `Header` / `Footer`
- главная, каталог, категория, товар, услуги, FAQ, контакты, доставка, thank-you
- универсальный pop-up заявки
- отдельные формы на страницах услуг и контактов
- mock-данные товаров, FAQ, категорий, оборудования

## Структура проекта

- `app/*` - страницы и layout
- `components/layout/*` - шапка, подвал, shell
- `components/shared/*` - секции, карточки, формы, modal, FAQ, gallery
- `components/page/*` - небольшие клиентские обвязки для CTA и modal
- `data/site.ts` - основные данные сайта, контакты, товары, FAQ, оборудование
- `lib/*` - небольшие helper-функции и выборка данных
- `types/index.ts` - типы данных

## Где менять реальные данные

- `data/site.ts`
  - `siteConfig` - название компании, телефон, email, Telegram, WhatsApp, адрес, режим работы
  - `products` - реальные товары, фото, совместимость, цены, материалы, сроки
  - `categories` - список категорий и описания
  - `faqItems` - реальные ответы FAQ
  - `equipment` - формулировки блока про оборудование
  - `homeCases` - реальные кейсы и фото
